# 💬 MediaHub — Subtitle Generator (AI)

Generador de subtítulos con Inteligencia Artificial usando **Whisper** de OpenAI. Parte del ecosistema **Media Hub**.

## Funcionalidad
- Transcribe audio o video a archivos .srt
- Procesamiento local (sin internet una vez instalado el modelo)
- Soporte multilenguaje con detección automática

## Instalación
\\\powershell
pip install -r requirements.txt
\\\

## Ejecución
\\\powershell
python main.py
\\\

> Parte del ecosistema [Media Hub](https://github.com/Media-Hub-Site)
